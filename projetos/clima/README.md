# ⛅ Clima Agora

Aplicativo de previsão do tempo que consome a API pública [Open-Meteo](https://open-meteo.com/).

## Funcionalidades

- Busca de cidades com sugestões enquanto você digita (com navegação pelo teclado)
- Clima atual: temperatura, sensação térmica, umidade e vento
- Previsão para os próximos 5 dias
- Botão para usar a localização atual (Geolocation API)
- Cores de fundo que mudam conforme o clima e o horário
- Lembra a última cidade pesquisada

## Conceitos praticados

`fetch` com `async/await`, tratamento de erros de rede, debounce, `URLSearchParams`, `Intl.DateTimeFormat` e consumo de APIs REST sem chave.

## Como rodar

Abra o `index.html` no navegador. Não precisa de servidor nem de chave de API.
