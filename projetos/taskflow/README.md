# 📋 TaskFlow

Quadro Kanban para organizar tarefas, feito com **HTML, CSS e JavaScript puro**.

## Funcionalidades

- Três colunas: A fazer, Em andamento e Concluído
- Arrastar e soltar tarefas entre as colunas
- Criar, editar e excluir tarefas
- Prioridade (baixa, média, alta), com ordenação automática
- Prazo, com destaque para tarefas atrasadas
- Busca por título ou descrição
- Dados salvos no navegador (LocalStorage)

## Conceitos praticados

Manipulação do DOM, eventos, Drag and Drop API, `<dialog>`, `<template>`, LocalStorage e layout responsivo com CSS Grid.

## Como rodar

Abra o `index.html` no navegador. Não precisa de servidor.
